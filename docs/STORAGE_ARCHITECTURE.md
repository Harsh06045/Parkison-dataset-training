## 2. Security & HIPAA Compliance Features

### 2.1 Cryptographic SHA-256 Checksums
Every file ingested or generated by the system is passed through `hashlib.sha256()` on write. The resulting 64-character hexadecimal digest is recorded in the `file_references` table:
```python
hasher = hashlib.sha256()
with open(filepath, "rb") as f:
    for chunk in iter(lambda: f.read(65536), b""):
        hasher.update(chunk)
sha256_hash = hasher.hexdigest()
```
This guarantees immutability and verifiable tamper-detection.

### 2.2 Token-Authenticated Signed URLs
Files cannot be accessed via direct predictable paths. Stored artifacts require a signed, URL-safe 32-character access token:
```text
GET /api/parkinson/storage/{file_id}?token=NlmbRfmcSFvZZRIP...
```
- Tokens have a configurable Time-To-Live (default: 72 hours).
- Expired tokens or invalid tokens return `HTTP 401 Unauthorized` or `HTTP 403 Forbidden`.
- Doctors and Administrators can bypass token expiry using authenticated JWT bearer credentials.

### 2.3 Path Traversal Prevention
Filename sanitization strips directory traversal vectors (`..`, `/`, `\`), generating collision-free deterministic storage names:
```python
unique_filename = f"{prediction_id}_{file_type}_{token[:8]}{ext}"
```
